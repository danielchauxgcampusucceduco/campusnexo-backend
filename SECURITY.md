# Seguridad

Este repositorio es un proyecto académico en estado de prototipo. No almacenes datos personales, imágenes, credenciales reales ni información interna de la universidad en issues, logs, commits o solicitudes de cambio.

La API no incorpora autenticación ni autorización y no está preparada para exponerse públicamente como servicio. Antes de un despliegue institucional se deben agregar controles de acceso por rol, TLS, gestión de secretos, revisión de dependencias, retención de datos y monitoreo.

Si encuentras una vulnerabilidad, repórtala mediante un GitHub Security Advisory privado en este repositorio; evita publicar detalles explotables en un issue abierto.
